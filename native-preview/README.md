# Native edition website — local release draft

This folder is a concrete landing page and policy draft for the native Kotlin/SwiftUI
edition, prepared27 September2026. The published root pages are unchanged.

It uses the original Everbit vector icon and locally bundled OFL fonts. No remote font,
analytics, form submission, fictional store badge, or mock app screenshot is included.

Before promotion: accept real device builds; verify policy against final permissions,
storage and SDKs; add verified store URLs; remove the release-preview/draft copy;
copy the accepted pages/assets into the Pages root and verify relative links. Publish
through this existing GitHub Pages repository, keeping app source and signing private.

Store screenshots must come from the accepted native binaries. Preview artwork is
not a substitute for phone/tablet/iPad captures. Account declarations and personal
Apple signing remain separate release tasks.
